**最方便的方式**：在**运营后台**标记坏例（网址是助手网址后面加 `/admin`）：
```
https://ai-fulfillment-assistant-ihfrvqkvdvkgkdwczy5rv6.streamlit.app/admin
```
1. 进后台 → 左侧填昵称 → 点"测评管理"
2. 在"坏例闭环"里找到那条对话 → 点"标记为坏例" → 填"为什么是坏例"
3. 确认后它会自动进 Eval 用例 + BUG 反馈单

**或者**：直接微信发我：问题 + 它答的 + 你觉得哪不对。

## 🧪 你可以测这四类功能

### 1️⃣ 问时效（多久能到）
```
- 买书架送到 SP 要多久？
- b1a812 多久能发货？
- 咖啡送到 RN 要几天？
- 从 SP 发到 MG 要多久？
```

### 2️⃣ 问卖家风险（靠不靠谱）
```
- b1a812 这家靠谱吗？
- 6560211a 退货方便吗？
- 推荐个卖书架的靠谱商家
```

### 3️⃣ 问价格（多少钱）
```
- b1a812 和 6560211a 哪个便宜？书架，送到 RN
- 咖啡运费一般多少？
- 电脑平均多少钱？
```

### 4️⃣ 对比 / 排名（多对象比）
```
- b1a812 和 6560211a 谁发货快？
- 哪些品类运费最贵？
- 推荐个卖咖啡的，送到 RN
```

## 🎯 特别希望你能测的（我担心的地方）

1. **换着问法测**：同一个意思换几种说法，看它能不能听懂。比如：
   - "多久能到" / "几天能收到" / "什么时候能到货"（应都回答时效）
   - "靠谱吗" / "会不会是骗子" / "这家店行不行"（应都回答风险）

2. **追问测试**：先问一句，再补信息追问：
   - 先问"推荐个卖咖啡的" → 再答"我在RN"（看它能不能记住）

3. **乱问测试**：故意问它做不到的：
   - "帮我砍价" / "给我查物流到哪了" / "今天天气怎么样"（应温和回应，不硬编）

4. **填奇怪的州**：比如"送到 XX 州"（不存在的）→ 应提示无效，不瞎编
