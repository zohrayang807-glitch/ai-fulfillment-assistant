# 用户履约旅程实测表（4 平台 × 3 阶段）

> 方法：在淘宝 / 小红书 / 京东 / 抖音各下一单，在**售前 / 售中 / 售后**三个阶段，分别向平台的 **AI 助手 / 客服**问履约问题，记录它们的反馈。
> 目的：验证"履约数据驱动的购物助手"的实际缺口——用户真实履约旅程里，谁能答、谁不能。
> 记录要点：① 谁回答的（AI / 客服 / 只能自己看页面）② 给了准确数据，还是建议，还是"查不到"。

---

---

## 填写时的记录符号（可选）

- **🅰️ AI 助手**：平台自带的 AI 购物助手回答
- **🎧 客服**：人工/店铺客服回答
- **👀 页面**：只能自己去看页面信息，没人答
- **✅ 准确 / 🟡 给建议 / ❌ 查不到**

示例：`🅰️ 给了建议但不准` 或 `❌ 查不到，让我自己看页面`

---

## 填完后我来做的分析

1. **四平台 × 三阶段**的能力矩阵（谁能答履约问题、谁不能）；
2. **缺口提炼**：哪类履约问题（时效/退货/物流）是普遍没人答的；
3. 把你的产品定位进去：**"这些没人答的问题，我的助手用履约数据回答"**。
